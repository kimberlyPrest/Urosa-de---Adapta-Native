# Urosaude — Adapta Native

Repositorio documental e operacional do sistema financeiro da Urosaude & Associados.

- `01_projeto/`: objetivo, visao e constituicao.
- `02_reunioes/`: registro de reunioes disponibilizado para o projeto.
- `03_documentos/`: escopo, matriz e fixtures sanitizadas.
- `04_fase-atual/`: fase aberta, SPECs, tasks e matriz operacional.
- `05_entregas/`: fases encerradas futuramente.
- `06_notas/`: notas operacionais e debug.

A Fase 1 esta documentada; a implementacao ainda nao foi iniciada neste commit.
